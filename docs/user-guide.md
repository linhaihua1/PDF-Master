# PdfKit 用户操作手册

> 适用版本：1.2.0　|　适用系统：Windows 10 / 11（64 位）

PdfKit 是一个离线运行的 PDF 处理工具，内置 60 项功能。**不需要联网、不需要安装 Java、不需要 Office**，全部处理都在你自己的电脑上完成，文件不会上传到任何地方。

## 一、安装与卸载

### 安装

1. 下载 `PdfKit-1.2.0.exe`（约 72 MB）。
2. 双击运行安装程序。
3. 选择安装位置（也可以直接用默认位置），点「下一步」完成安装。
4. 安装程序会创建桌面快捷方式和开始菜单项。

**不需要预装任何东西**。Java 运行环境、中文字体都已经打包在安装包里。

### 卸载

两种方式任选：

- **设置 → 应用 → 已安装的应用** → 找到 PdfKit → 卸载
- **控制面板 → 程序和功能** → 找到 PdfKit → 卸载

卸载会一并删除程序文件和配置。**你在「文档」文件夹里生成的结果文件不会被删除**，需要自己清理。

### 便携使用（免安装）

如果拿到的是绿色版文件夹（`PdfKit` 目录），整个文件夹复制到任何位置，双击里面的 `PdfKit.exe` 即可运行，不写注册表、不需要安装。

## 二、界面导览

启动后界面分四个区域：

```
┌──────────────────────────────────────────────────────────┐
│  ① 顶部：文件选择 · 输出目录 · 开始执行                    │
├────────────────┬─────────────────────────────────────────┤
│  ② 左侧       │  ③ 右侧                                 │
│  功能树        │  功能说明 + 参数表单                     │
├────────────────┴─────────────────────────────────────────┤
│  ④ 下方：任务队列 · 执行结果                              │
├──────────────────────────────────────────────────────────┤
│  ⑤ 状态栏                                                 │
└──────────────────────────────────────────────────────────┘
```

### ① 顶部：文件与执行

| 元素 | 说明 |
|---|---|
| **选择文件** | 点一下弹出文件选择框，可以按住 Ctrl 多选。选中的文件名会显示在旁边 |
| **输出目录** | 结果保存到哪里。默认是「文档 \ PdfKit」，可以点「浏览」改 |
| **开始执行** | 提交当前任务到队列 |

### ② 左侧功能树

60 项功能按 8 个分类归组，点分类前面的三角展开，点功能名切换右侧表单。

分类依次是：页面组织（18 项）、内容编辑（15 项）、格式转换（7 项）、表单处理（3 项）、书签与目录（3 项）、安全与合规（8 项）、读取与分析（3 项）、优化与修复（3 项）。

### ③ 右侧表单

上方是当前功能的用途说明，下方是参数。每个参数左边是名称，中间是输入控件，右边灰色小字是填写提示（把鼠标停在输入框上也能看到）。

部分功能没有参数，会显示「这个功能不需要额外设置」。

### ④ 下方任务区

**任务队列**显示每个任务的状态、进度和消息。可以同时跑两个任务，第三个会排队。

**执行结果**区域显示两类内容：
- 分析类功能（文档信息、字体体检、结构探查）的结论
- 执行完成/失败的消息

### ⑤ 状态栏

显示当前操作结果。绿色表示成功，红色表示失败，灰色是进行中的进度。

## 三、基本操作流程

所有功能都是同一套流程：

```
1. 选文件  →  2. 选功能  →  3. 填参数  →  4. 点执行  →  5. 去输出目录取结果
```

### 详细步骤

1. **选文件**：点顶部「选择文件」。多数功能只需要 1 个文件；合并、叠加需要 2 个以上。
2. **选功能**：在左侧树里点你要的功能，右侧会出现对应参数。
3. **填参数**：按提示填。带默认值的可以直接用默认值。**填错了不用怕**，程序会告诉你是哪个参数有问题。
4. **点执行**：任务出现在下方队列里，能看到进度。
5. **取结果**：结果保存在输出目录，文件名会带后缀（如 `合同_合并.pdf`），**不会覆盖原文件**。

### 几个要点

**原文件永远不会被修改。** 所有功能都生成新文件。如果算出来的输出名和原文件重名，会自动改名成 `xxx_1.pdf`。

**同名文件不会被覆盖。** 输出目录里已有同名文件时，新文件会自动加序号。

**可以中途取消。** 任务在执行时，选中那一行点「取消」，会在下一个检查点停下。

## 五、功能详解 · 页面组织（18 项）

### 1. 合并 PDF

把多个 PDF 按你选择的顺序接成一个文件。

| 参数 | 说明 |
|---|---|
| 保留书签 | 勾选后，每个源文件在结果里生成一条一级书签（用文件名命名），方便跳转 |

**注意**：合并顺序就是你选文件的顺序，选之前理一下顺序。只选 1 个文件会提示「至少需要 2 个」。

---

### 2. 拆分 PDF

把一个大文件拆成多个小文件。

| 参数 | 说明 |
|---|---|
| 拆分方式 | **按页数**：每 N 页一个文件<br>**按页码范围**：按你写的范围各生成一个文件 |
| 每几页一个文件 | 按页数模式生效。填 10 就是每 10 页一个文件 |
| 页码范围 | 按范围模式生效。写 `1-3,4-8,9-` 会生成 3 个文件（1-3 页、4-8 页、9 页到末尾） |

---

### 3. 旋转页面

把页面转正。

| 参数 | 说明 |
|---|---|
| 旋转角度 | 顺时针 90 / 180 / 270 度 |
| 作用页 | 留空 = 全部页；只转某几页写 `1-3,5` |

**注意**：这是修改「显示方向」，不是转动内容。扫描时纸张放反了用这个能救回来。

---

### 4. 裁剪页面

裁掉四周留白，或者往外套一点边距。

| 参数 | 说明 |
|---|---|
| 上/下/左/右边距(mm) | 正数往里裁，**负数往外扩**。全填 0 等于不裁 |

**注意**：裁太多导致页面没有内容时会提示「裁剪过多」并拒绝执行，这是保护机制。

---

### 5. 删除页面

| 参数 | 说明 |
|---|---|
| 要删除的页 | **必填**。如 `2,5-7` |

**注意**：不允许把全部页面都删掉，会提示「不能删除全部页面」并拒绝执行。

---

### 6. 提取页面

只保留你要的页，生成新文件。

| 参数 | 说明 |
|---|---|
| 要保留的页 | **必填**。如 `1-3,8` |

与「删除页面」正好相反：一个说「留下什么」，一个说「删掉什么」。留下 90% 用删除，留下 10% 用提取。

---

### 7. 重排页面

| 参数 | 说明 |
|---|---|
| 新页序 | **必填**。如 `3,1,2,5-8` |

**用途**：调整顺序。也可以重复写某一页来实现「复制页」——写 `1,1,2` 会得到「第 1 页、第 1 页、第 2 页」。

---

### 8. 缩放页面

| 参数 | 说明 |
|---|---|
| 缩放比例(%) | 50–200 |
| 作用页 | 留空 = 全部页 |

**注意**：缩小是为了把内容装进更小的纸；放大时如果超出纸张会被裁掉，慎用。

---

### 9. 按章节拆分

按书签把文档拆开，每个章节一个文件。

| 参数 | 说明 |
|---|---|
| 按第几级书签 | 一般填 1（一级章节） |
| 文件名带章节标题 | 勾选后文件名用章节名，否则用「原文件名_序号」 |

**前提**：文件里得有书签。没有书签会提示。可以先用「自动生成书签」造一份。

---

### 10. 多页排版（N-up）

把多页缩到一页上，省纸用。

| 参数 | 说明 |
|---|---|
| 每页排几页 | 2×1 / 1×2 / 2×2 / 3×3 |
| 纸张 | A4 竖版 / A4 横版 |
| 页边距(mm) | 8 左右比较合适 |
| 格间距(mm) | 格子之间的空隙，4 左右 |
| 画分隔线 | 勾选后每格周围画一条浅灰框，打印后好裁 |

**注意**：缩放后的字会变小。原文档字本来就小的话，2×2 打过可能看不清。

---

### 11. 按大小拆分

按目标体积拆文件，适合发邮件（附件通常限 10–25 MB）。

| 参数 | 说明 |
|---|---|
| 每个文件不超过(MB) | 填你邮箱的附件上限，一般 10 或 20 |

**注意**：这是「尽量不超过」，单页本身超限时那个文件还是会超。

---

### 12. 叠加文档

把第二个文件盖到第一个文件的每页上。常用于套信纸模板、盖印章页。

| 参数 | 说明 |
|---|---|
| 叠加到 | 全部页 / 奇数页 / 偶数页 |
| 叠加层透明度(%) | 100 = 完全不透明 |

**用法**：先选正文文件，再选模板文件（模板背景要透明）。程序会把模板贴到正文每一页上。

---

### 13. 海报分块打印

一页放大切成多张 A4，打出来拼成大海报。

| 参数 | 说明 |
|---|---|
| 横向切几块 / 纵向切几块 | 2×2 就是 4 张 A4 |
| 重叠(mm) | 相邻块之间多留一点，粘的时候好对齐，5 左右 |
| 打印对位标记 | 四角画裁切线 |
| 作用页 | 一般是 `1`（只处理第一页那张大图） |

---

### 14. 小册子拼版

按骑马钉顺序排页，双面打印后对折就是一本小册子。

| 参数 | 说明 |
|---|---|
| 中缝宽度(mm) | 装订留白，0 表示不留 |
| 画中缝参考线 | 勾选后中缝画一条虚线，方便折 |

**用法**：
1. 先正常打印处理后的文件（记得选「双面打印，短边翻转」）
2. 沿中缝对折
3. 页数不足 4 的倍数会自动补空白页，不会破坏页码顺序

---

### 15. 按文本筛选页面

只保留（或排除）含某关键词的页。

| 参数 | 说明 |
|---|---|
| 关键词或正则 | 普通词直接写，如 `发票` |
| 按正则解释 | 勾选后可以用 `发票\|金额\d+` 这种模式 |
| 反向：排除匹配页 | 勾选后保留的是「不含关键词」的页 |
| 区分大小写 | 只对英文有效 |

**注意**：
- 扫描件没有文字层，搜不到内容。这种情况用「按有无图片筛选」。
- 一个词都搜不到时会提示「没有页面符合条件」并且**不生成文件**——避免你拿到一个空文件。

---

### 16. 按尺寸筛选页面

| 参数 | 说明 |
|---|---|
| 筛选条件 | 竖版 / 横版 / A4 / Letter |

**用途**：一份文档里混了几张横版扫描页，用「竖版」筛一下就能挑出来单独处理。

---

### 17. 删除空白页

| 参数 | 说明 |
|---|---|
| 最少字符数 | 少于这个字数算空白，默认 3 |
| 把含图片的页也算非空 | **扫描件必须勾选**，否则会把所有扫描页当空白删掉 |

**注意**：
- 判断标准是「文字数不足 **且** 没有图片」。所以有图的页一律保留。
- 如果算出所有页都是空白，会拒绝执行并提示——这通常说明判定出问题了，不要强行继续。

---

### 18. 按有无图片筛选

| 参数 | 说明 |
|---|---|
| 保留 | 含图片的页 / 不含图片的页 |

**用途**：把图文混排的册子拆成「纯文字部分」和「图片部分」分别处理。

---

## 六、功能详解 · 内容编辑（15 项）

### 19. 添加页码

| 参数 | 说明 |
|---|---|
| 位置 | 左下 / 底部居中 / 右下 / 左上 / 顶部居中 / 右上 |
| 页码格式 | 支持占位符 `{page}`（当前页）和 `{pages}`（总页数）<br>例：`第 {page} 页 / 共 {pages} 页`、`- {page} -` |
| 起始页 | 从文档的第几页开始加。用它实现「封面不加页码」 |
| 起始序号 | 第一页显示成几。用它实现「正文从 1 开始编号」 |
| 字号 | 10 左右比较合适 |
| 边距(mm) | 距纸张边缘的距离 |
| 作用页 | 留空 = 全部页 |

**两个「起始」的区别**（容易搞混）：

假设有 5 页封面 + 20 页正文，想让正文显示「第 1 页」：
- 起始页 = 6（从第 6 页开始加）
- 起始序号 = 1（第 6 页上显示 1）

只填起始序号=1 的话，封面也会被编上号。

---

### 20. 添加水印

| 参数 | 说明 |
|---|---|
| 水印文字 | 支持中文，默认「内部资料」 |
| 字号 | 48 比较显眼 |
| 旋转角度 | 0 / 30 / 45 / 90，斜着一般是 45 |
| 透明度(%) | 默认 15。**调太深会盖住正文** |
| 颜色 | 灰色 / 红色 / 蓝色 / 黑色 / 浅灰 |
| 平铺 | 勾选后整页重复铺满，不勾就是一页一个大字 |

**建议**：正式文档用「灰色 + 15% 透明度 + 45 度」，既明显又不影响阅读。

---

### 21. 页眉页脚

在六个位置写文字。

| 参数 | 说明 |
|---|---|
| 页眉左 / 中 / 右 | 页面上方的三个位置 |
| 页脚左 / 中 / 右 | 页面下方的三个位置 |
| 字号 | 9 左右 |

### 44. 自动生成书签

## 十、功能详解 · 安全与合规（8 项）

### 47. 添加密码

| 参数 | 说明 |
|---|---|
| 打开密码 | 打开文件时必须输入。**这才是真正保护内容的密码** |
| 权限密码 | 用于修改权限设置，留空则与打开密码相同 |
| 允许打印 | 不勾则禁止打印 |
| 允许复制内容 | 不勾则禁止复制文字 |

**两个密码的区别**（重要）：

- **打开密码**：没有它打不开文件。这是加密的实际意义。
- **权限密码**：不知道它也能打开文件，只是不能改「能不能打印/复制」这些限制。

**只填权限密码、留空打开密码的话，文件其实谁都能打开。** 所以程序要求两个至少填一个。

**加密强度固定为 AES-256**，没有弱加密选项。

### 50. 自动涂黑（敏感信息）

### 52. 证书签名

给 PDF 加数字签名（PKCS#7 格式）。

| 参数 | 说明 |
|---|---|
| 证书文件(.p12/.pfx) | 留空则自动生成自签名证书 |
| 证书密码 | 自签名时默认 `PdfKit123` |
| 证书别名 | 留空取文件里第一个 |
| 证书名称 | 自签名证书上显示的名字 |
| 签名原因 | 如「文档确认」 |
| 签名地点 | 如「中国」 |
| 导出自签名证书 | 勾选后把 `.p12` 一并存到输出目录，下次可以复用 |

**自签名 vs 正式证书**：

- **自签名证书**：自己生成、自己用，免费。别的电脑上打开会显示「签名有效，但签发者不受信任」。适合内部流转、证明「这个文件我确认过」。
- **正式证书**：需要向 CA 购买（如企业代码签名证书）。别人才会看到「签名有效且受信任」。

**重要**：签名只能证明「签署后文件没被改过」。如果把文件另存、转格式、加密，原签名就会失效。

### 53. 验证签名

列出文档里的数字签名，检查每个签名的**覆盖范围是否完整**（签名后有没有被追加内容）。没有参数。

**能力边界要说清楚**：这一项只做结构与覆盖检查，**不校验证书链、不判断根证书是否受信任**。

所以它能告诉你：
- 文件里有没有签名、是谁签的、什么时候签的
- 签名覆盖了哪些内容，签名之后文件有没有被改动过

它**不能**告诉你：
- 这张证书是不是真的由某 CA 签发（是否被吊销、是否过期）
- 签署人身份是否可信

需要确认证书链与信任关系时，请用 Adobe Acrobat 或专业签名验证工具。本工具在这一点上只能做初步检查。

- 移除后签名失效
- 页面上已经渲染的签名外观（那行「已由 XX 签署」的字）仍留在页面上，需要自己用别的方式处理
- 如果文件有其他人在用，移除签名可能造成争议，操作前想清楚

| 清空元数据 | 勾选后能再小一点点 |

**注意**：
- 压缩的主力是**图片重采样**。纯文字的 PDF 本来就没有多少图可压，压缩后体积可能不变甚至略增——程序会明确提示这一点，不是功能失效。
- 扫描件收益最大（通常能压 50–80%），已经是电子版排版的文档收益很小。

---

### 59. 修复 PDF

重新解析并重写文件结构，修复交叉引用表损坏、文件结尾缺失这类问题。

没有参数，直接执行。**不是万能的**——内容流本身损坏的话修不回来。修完能用就用，不能用就只能找原始文件。

---

### 60. 画质增强

对模糊、发灰的扫描页做锐化、去噪、对比度提升。

| 参数 | 说明 |
|---|---|
| 输出分辨率 | 200 适合阅读，300 适合再打印 |
| 锐化强度(%) | 60 适中，200 会很硬 |
| 对比度(%) | 110 轻微提升，太大暗部会糊死 |
| 去噪强度 | 0–3，噪点多的扫描件调到 2 |
| 转灰度 | **合同、书籍扫描件建议勾选**，文件小很多且更像正式文件 |

**注意**：这是像素级处理，处理后页面的文字层情况不变——原本有文字层的还能提取，原本是扫描图的仍然是图。

## 十三、通用规则

### 页码怎么写

很多功能的「作用页」「页码」参数都支持同一套写法：

| 写法 | 含义 |
|---|---|
| 留空 | 全部页 |
| `3` | 第 3 页 |
| `1-3` | 第 1 到 3 页（含首含尾） |
| `8-` | 第 8 页到末页 |
| `-5` | 第 1 页到第 5 页 |
| `1,3,5` | 第 1、3、5 页 |
| `1-3,7,9-` | 组合使用 |

分隔符可以用半角逗号、全角逗号、分号或空格，都认。

**页码从 1 开始**，就是你在 PDF 阅读器里看到的页数序号（不是文档里印的页码）。

### 输出文件名规则

- 结果文件名 = 原文件名 + 功能后缀，如 `合同.pdf` → `合同_合并.pdf`
- 重名时自动加序号：`合同_合并_1.pdf`、`合同_合并_2.pdf`
- **绝不覆盖原文件**，也不会写到源文件旁边（都写到输出目录）
- 多页导出（如转图片）会建一个子文件夹

### 文件不会被上传

所有处理都在本机完成。程序不联网、不上传任何内容、不收集任何信息。

### 同时跑多个任务

可以同时跑 2 个任务，第 3 个会排队。每个任务的临时文件互相隔离，不会串。

不过 PDF 处理比较吃内存，同时跑两个大文件（500 页以上）可能变慢，建议排队执行。

## 十四、常见问题

### 处理完的文件在哪里？

在你设置的「输出目录」里。默认是 `C:\Users\你的用户名\Documents\PdfKit`。

点顶部的「浏览」可以改。处理完可以在状态栏或任务队列看到生成的文件名。

### 为什么处理后文件变大了？

常见原因：

- **加了水印/页码**：会往每页写内容，文件必然变大。加了中文字体的还会嵌入字体子集（每个文件约增加 40 KB）
- **压缩后反而变大**：纯文字 PDF 没有图片可压，重新编码可能略增。看任务消息里的提示
- **PDF 转图片**：PNG 无损压缩体积很大，改用 JPG 或降低 DPI

### 中文变成方框了？

理论上不会发生——中文字体已经打包在程序里。

如果真遇到了，说明程序用的是后备方案（系统字体），反馈时请附上日志文件（见下一节）。

### 扫描件搜不到文字 / 提取不出文本？

扫描件是「图片」，里面没有文字信息。本工具**不含 OCR**（文字识别）功能。

能做的：
- 提取内嵌图片（把扫描图导出来）
- 画质增强（让扫描图更清楚）
- 压缩（减小体积）

需要文字的话，得用专门的 OCR 工具先处理一遍。

### 涂黑之后还能还原吗？

**不能**。自动涂黑和手动涂黑都是把整页转成图片、原文字彻底删除。这是设计上故意的——能还原的涂黑等于没涂。

但反过来要注意：**处理过的页不能再选中文字、不能搜索**。如果既需要打码又需要保留文字层，只能手工用其他工具逐个改。

### 数字签名为什么显示「不受信任」？

因为用的是自签名证书。这只影响「签发者可信度」的显示，不影响「文件是否被篡改」的判断。

要显示为受信任，需要向 CA 购买正式证书。内部使用的话自签名完全够用。

### 能不能批量处理 100 个文件？

可以，一次把文件都选中，然后执行。任务队列会依次处理。

但要注意：所有文件用同一套参数。需要不同参数的话得分批做。

### 界面上的中文显示成方块 / 乱码？

说明系统缺少界面字体（微软雅黑）。这在精简版 Windows 上会遇到。装一下微软雅黑或者任意中文字体即可。

注意这与「PDF 输出里的中文」是两回事——输出用的字体是内置的，不受影响。

## 十五、故障排查

### 找到日志文件

出问题时最重要的就是日志。位置：

```
C:\Users\你的用户名\AppData\Local\PdfKit\logs\pdfkit-年月日.log
```

快速打开的方法：在文件资源管理器地址栏粘贴 `%LOCALAPPDATA%\PdfKit\logs` 回车。

日志按天分文件，记录了每次启动、每个任务的结果、以及所有错误详情。

### 常见错误提示的含义

| 提示 | 原因 | 怎么办 |
|---|---|---|
| 请先选择文件 | 没选文件就点了执行 | 点顶部「选择文件」 |
| 这个 PDF 已加密，请提供打开密码 | 文件有密码 | 在参数里填密码，先解密再处理 |
| 无法解析 PDF（文件损坏或不是 PDF） | 文件损坏，或者根本不是 PDF | 先用「文档结构探查」看看，再试「修复 PDF」 |
| 文件不可读（可能被占用） | 另一个程序正打开着它 | 关掉 Acrobat / WPS / 浏览器里的预览，重试 |
| 磁盘空间不足 | 输出盘满了 | 清理磁盘，或换输出目录 |
| 这个 PDF 没有表单字段 | 文件不是可填写表单 | 用「读取表单字段」确认一下 |
| 没有匹配到任何字段 | 字段名写错了 | 先执行「读取表单字段」，照抄字段名 |
| 没有页面符合条件 | 筛选条件太严或关键词不对 | 放宽条件；扫描件改用「按有无图片筛选」 |
| 所有页都被判定为空白 | 判定失效（常见于纯扫描件没勾「含图片算非空」） | 勾上「把含图片的页也算非空」重试 |
| 系统未找到可用中文字体 | 极罕见，内置字体加载失败 | 装一个中文字体（微软雅黑），或反馈问题 |

### 程序打不开 / 启动闪退

1. 检查是否已经有一个 PdfKit 在后台跑着（任务管理器里找 `PdfKit.exe`），结束它再启动
2. 打开日志目录看最新一条记录
3. 如果日志里完全没有启动记录，说明程序在更早的阶段就失败了，试试重新安装

### 界面卡住 / 任务不动了

PDF 处理是密集计算，处理大文件时界面会变慢，这是正常的。可以看任务队列里的进度百分比是否在推进。

如果进度长时间（几分钟）不动：
1. 点「取消」，等它停下
2. 用「压缩 PDF」先减小文件体积再试
3. 检查是否同时在跑两个大任务，等一个跑完再试

### 想彻底重置

关闭程序，删除这个文件夹：

```
%LOCALAPPDATA%\PdfKit
```

它会重建。注意这会清掉日志和所有临时文件，但**不会**动你输出目录里的结果文件。
